# Greece Wildfire Analysis (2000–2025)

Annual burned area mapping across Greece using MODIS satellite data processed via Google Earth Engine, rendered as an interactive Folium map.

## Overview

Uses the MODIS MCD64A1 v6.1 burned area product to extract and visualise yearly fire footprints across Greece from 2000 to 2025. Each year is rendered as a toggleable layer on a Carto basemap, allowing year-by-year comparison of burn extent.

## Output

Interactive HTML map — each year is a separate toggleable layer. Open `greece_burned_2000_2025.html` in a browser.

## Tools

- Python, Google Earth Engine, Folium
- Data: MODIS MCD64A1 v6.1 — NASA / UMD
